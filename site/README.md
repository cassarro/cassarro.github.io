# roderickcassar.com

Personal site for [Roderick Cassar](https://www.roderickcassar.com/) — product and technology leader at Entain, working on Global Casino Integrations.

Built with Jekyll. Live on GitHub Pages from [cassarro/cassarro.github.io](https://github.com/cassarro/cassarro.github.io).

## Run locally

```bash
bundle install
bundle exec jekyll serve
```

Open [http://127.0.0.1:4000](http://127.0.0.1:4000).

## What’s here

- Homepage: about, skills, services, experience (including current Entain role), certifications, writing
- SEO: `jekyll-seo-tag`, `jekyll-sitemap`, Person/ProfilePage JSON-LD, Open Graph image
- Analytics load only after cookie consent
